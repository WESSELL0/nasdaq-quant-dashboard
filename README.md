# 多资产投资决策台 使用说明

本说明适用于：

* 第一次使用本项目（自动安装依赖）
* 之后日常打开使用
* Windows 用户

你的运行方式已经被简化为：

* **第一次使用**：双击 `first_nasdaq_app.bat`
  自动安装依赖并启动网页
* **以后使用**：双击 `nasdaq_app.bat`
  直接启动，无需再次安装

## 这是什么

这是一个基于 Streamlit 的统一多资产决策网页，当前集成了 4 个面板：

* 纳斯达克 100
* 黄金
* 比特币
* 恒生科技

页面目标不是喊单，而是把“当前评分、当前建议、核心原因、技术位置、数据可信度”放在同一套结构里，方便横向比较。

## 当前页面结构

每个资产面板都采用同一套阅读顺序：

1. 顶部摘要区：总分 + 当前建议 + 当前参考价 + 一句话判断
2. 走势曲线
3. 为什么这样判断
4. 核心因子
5. 技术面与数据状态

## 当前展示规则

### 评分主视觉

四个资产顶部最大的数字都是“综合分”，价格只作为辅助展示。

### 黄金价格

黄金支持两种参考口径展示：

* 人民币 / 克
* 美元 / 盎司

顶部摘要会展示两种口径，例如：

* 人民币价：`¥713.2 / 克`
* 国际价：`$3,088.42 / 盎司`

说明：

* 人民币 / 克是换算参考价
* 美元 / 盎司是国际参考价
* 二者都不是唯一成交价，也不是金饰零售价

### BTC 价格

比特币支持两种参考口径展示：

* 人民币 / 枚
* 美元 / 枚

顶部摘要会展示两种口径，例如：

* 人民币价：`¥516,348 / 枚`
* 美元价：`$71,376 / 枚`

### 恒生科技价格

恒生科技当前展示的是 ETF 代理价，不是恒生科技指数点位本体。页面会明确标注代理属性，并配合环境分、技术分和辅助项一起使用。

## 数据口径原则

项目当前遵循以下原则：

1. 不静默伪装关键值
2. 不用错误口径代理硬套真实阈值
3. 缺失就显示缺失，不强编
4. 有 fallback 会明确展示
5. 代理价会明确说明，不伪装成现货或指数本体

## 数据说明

### 纳斯达克 100

* 价格：`^NDX`
* 宏观：VIX / 10Y / DXY
* 估值：QQQ trailing PE
* 输出：综合分、当前建议、历史技术分位近似值、风控倍率

### 黄金

* 趋势代理：`GLD`
* 国际价：优先 `GC=F`，其次 `XAUUSD`，再次 `GLD` 近似反推
* 人民币价：国际金价 × USD/CNY ÷ 31.1035
* 输出：综合分、环境判断、动作建议、做T建议

### 比特币

* 价格：`BTC-USD`
* 人民币参考价：BTC 美元价 × USD/CNY
* 输出：综合分、环境判断、动作建议、波段建议

### 恒生科技

* 价格代理：`3033.HK / 3067.HK` 等 ETF 代理
* 环境项：DXY / 10Y / USD/CNY / 恒指方向辅助项
* 输出：综合分、环境判断、动作建议、左侧提示

## 运行方式

### 方式一：推荐给大多数用户

直接双击：

* `first_nasdaq_app.bat`：第一次使用
* `nasdaq_app.bat`：后续日常使用

### 方式二：命令行启动

在项目目录执行：

```powershell
py -m streamlit run nasdaq_app.py
```

如果本机默认 Python 不是目标环境，也可以用完整解释器路径运行。

## 注意事项

* 页面结果仅作辅助判断，不构成投资建议
* 外部行情源可能限流或波动，页面会尽量 fallback，但可信度可能下降
* 黄金与 BTC 的人民币价格都是参考换算价，不是唯一成交价
* 恒生科技当前展示的是 ETF 代理价，不应直接理解为指数点位本体
